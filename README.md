## 🚀 Key Course Highlights Covered

### 1. The Fundamentals (`01_basics` to `03_basics`)
* **Variables & Memory:** Deep exploration of stack (Primitive) and heap (Non-Primitive) memory allocation.
* **Type Conversions:** Tricky behaviors during type conversion operations.
* **Objects & Functions:** Mastery of functional definitions, execution contexts, block scopes, arrow functions, and Immediately Invoked Function Expressions (IIFE).

### 2. Deep Under the Hood (`04_call_stack`)
* In-depth documentation on the **Global Execution Context**, **Function Execution Context**, and the step-by-step nature of the **Call Stack**.

### 3. Iterators & Functional Programming (`06_iterations`)
* Modern array iterations using Higher-Order array methods including `forEach`, `filter`, `map`, and `reduce`.

### 4. DOM Manipulation & Async Behavior (`07_dom` to `10_advance`)
* Interacting with standard document structures dynamically.
* Demystifying AJAX, Fetch API, XMLHttpRequest endpoints, and managing native handling via modern **Promises** (`async`/`await`).

### 5. Object-Oriented JS & Prototypes (`11_class_and_oop` to `13_smi_holey_array`)
* Deep exploration of prototypical inheritance behavior.
* Custom implementation setups with `call`, `bind`, lexical scoping, classes, properties, and hidden array optimizations (SMI vs. Holey arrays).
